# How NOVA writes up an experiment

So that notes shared in chat are remembered consistently, describe experiments like this:

- **ID and name**: EXP-07, "Gamified onboarding v1"
- **Dates**: start and end
- **Feature area**: onboarding, notifications, UI, pricing, paywall, referrals, …
- **Hypothesis**: one testable sentence
- **Conditions**: segment (new/existing users), platform (Android/iOS), plan price, and feature settings such as onboarding steps, gamification on/off, pushes per day, dark mode
- **Result**: metric, control rate, variant rate, lift, sample size, p-value
- **Interpretation at the time**: what the team concluded, in their words
- **Decision**: shipped, shelved, rolled back, planned next

When you change your mind about an old result, say so explicitly ("We now think…"), so RETRACE records it as a new dated belief rather than overwriting the old one.
